# Slice 10: Alert thresholds, save, rollback. Spec

Depends on slice 4 (Analyst layout) and slice 0 (AlertRuleSchema, evaluateRule). Inputs: design-system.md §6.12, §6.13; domain-model.md §8, §13 (scope: portfolio, region, market); architecture.md §7 (save machine); user-flows.md slice 10 (delete behind a confirm dialog).

## 1. Files
- `src/app/api/alerts/route.ts`: in-memory `Map<string, AlertRule>` in module scope; `GET` → `{rules: AlertRule[]}`; `POST` body validated with `AlertRuleSchema` (400 with zod issues on failure), assigns `id` (`crypto.randomUUID()`) and `createdAt`, waits 600 ms (simulated latency), returns 500 `{message:"Save failed (simulated)"}` when `?fail=1`, else 200 `{rule}`; `DELETE ?id=` → 204 (also honours `?fail=1`). `runtime = "nodejs"`. README notes the per-instance store.
- `src/features/alerts/api.ts`: typed fetchers using the shared schema; `listRules()`, `saveRule(rule, {fail})`, `deleteRule(id, {fail})`.
- `src/features/alerts/useAlertSave.ts`: TanStack `useQuery(["alerts"])` + `useMutation` with `onMutate` (cancel queries, snapshot, optimistic insert/update with a temp id and `pending: true`), `onError` (restore snapshot, set `failure` state for the Notice), `onSettled` (invalidate), `onSuccess` (set `savedAt`). Delete mutation likewise with optimistic removal and rollback.
- `src/features/alerts/AlertForm.tsx`: react-hook-form + `zodResolver(AlertRuleSchema)` + shadcn Form; fields per design-system.md §6.13 (Growth below %, Attainment below %, Scope select listing All markets (the portfolio), the 4 regions, the 13 markets grouped by region); defaults 0, 95, portfolio; `Simulate failure` checkbox (Analyst mode only) bound to the `fail` flag; primary `Save thresholds` disabled while invalid or saving; inline status text per §6.13 (`Saving…`, `Saved · just now`, then after 60 s `Saved`); on failure the `Notice` "Couldn't save" with body `Your thresholds were restored to the last saved values (growth below {g}%, attainment below {a}%).`, secondary `Try again` (re-runs the mutation with the same payload), ghost `Dismiss`.
- `src/features/alerts/RuleList.tsx`: one row per saved rule: sentence `Growth below 0% · Europe`, an evaluation line `${n} markets breach this rule: ${names}` (or `No markets breach this rule`) from `evaluateRule`, a pending style while optimistic (`--ink-muted` text + "Saving…"), and a `Delete` ghost button opening `DeleteDialog` (shadcn Dialog: title `Delete this rule?`, body `"Growth below 0% · Europe" will stop being evaluated.`, secondary `Cancel`, danger `Delete`). A failed delete restores the row and shows a Notice `Couldn't delete` with body `The rule was restored.` and a ghost `Dismiss`. Empty state: `No alert rules yet. Add one to watch a threshold.`
- `src/features/alerts/AlertsCard.tsx`: card titled `Alert thresholds` with form + list, placed in the Analyst layout after the heat map (full width).

## 2. Tests first
- `src/features/alerts/AlertForm.stories.tsx`: stories `Empty`, `Invalid` (attainment 120 typed in play), `Valid`, plus `Saving`, `Saved`, `Failed` row states for the list beneath, with `saveRule: fn()`. Play on `Invalid`: `aria-invalid`, message linked by `aria-describedby`, Save disabled. Play on `Valid`: Save enabled; submit calls `saveRule` with `{metric:"attainment", comparator:"below", threshold:95, scope:{regionId:"eu"}}`. `src/features/alerts/DeleteAlertDialog.stories.tsx`: `Open` story; play: Cancel has focus on open, the confirm button uses the danger variant. A11y addon passes on all.
- `tests/unit/useAlertSave.test.tsx` (`unit` project, `renderHook` with a `QueryClientProvider` wrapper and a mocked `fetch`): optimistic row appears before the response; on 500 the row reverts and `failure` is set; Try again re-posts. This is a hook, so it stays in Vitest per the slice 0 §10.0 scope guardrail.
- `tests/unit/alertsRoute.test.ts`: call the handlers directly: POST invalid → 400 with an issue at `threshold`; POST valid → 200 with id; `?fail=1` → 500; DELETE → 204.
- `tests/e2e/slice10.spec.ts`: the five criteria from user-flows.md slice 10 verbatim (invalid state; save shows Saving… then Saved and "3 markets breach this rule"; simulate failure shows 97 then the alert Notice then 95; schema ranges (unit); delete via dialog with the danger button).
