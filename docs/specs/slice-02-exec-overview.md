## 1. Outcome

## 2. Geo build (`scripts/build-geo.ts`, run once, output committed)
- Input: `world-atlas/countries-110m.json` from node_modules. Convert with `topojson-client.feature` to GeoJSON.
- Keep two layers: `markets`: the 13 features whose numeric id (string) is in `{ us:"840", ca:"124", de:"276", gb:"826", fr:"250", it:"380", es:"724", jp:"392", cn:"156", in:"356", au:"036", br:"076", mx:"484" }`, each with `properties: { marketId }`; `land`: every other country **except Antarctica (id `"010"`)** merged with `topojson-client.merge` into one MultiPolygon (so the backdrop is one path); dropping Antarctica keeps the populated world from being squeezed into the top three quarters of the frame.
- Output `public/geo/markets.json` as `{ type: "FeatureCollection", features: [land feature with properties {kind:"land"}, ...13 market features] }`. Round coordinates to 2 decimals (`topojson-simplify` is not needed; 110m is already coarse). Up to 100 KB uncompressed is acceptable (it gzips to roughly a third and is fetched once).
- Unit test `tests/unit/geo.test.ts`: the file has 14 features, every marketId in `data.json` appears exactly once, and `land` is a MultiPolygon.

## 3. Chart kit (`src/components/charts`)
- `Frame.tsx`: `<svg role={role} aria-labelledby={titleId} aria-describedby={descId}` where `role` is a prop defaulting to `"img"`; a chart that contains focusable marks (Choropleth markets, LineChart anomaly button, HeatMap cells, RadarChart vertices) passes `role="group"`, because `img` may not contain interactive descendants (axe `nested-interactive`). The `<title>` and `<desc>` still apply through the `aria-*` attributes. It renders `<svg viewBox={`0 0 ${width} ${height}`}>` with `<title>` and `<desc>` children; receives `width` from `@visx/responsive` `ParentSize`; height fixed per chart. Margins prop. Exposes a `<g>` for the plot area.
- `ChartTooltip.tsx`: uses `@visx/tooltip` `useTooltip` + a portal-free absolutely positioned div styled per design-system.md §6.8; props `{title, rows: Array<{label, value}>}`. Appears on hover and focus, dismissed on Escape and blur.
- `Legend.tsx`: items `{label, swatch: "line-solid" | "line-dashed" | "line-dotted" | "fill", color: cssVar}` rendered as described in §6.10.
- `ViewAsTable.tsx`: a toggle button (ghost, `table` icon 14 px, `aria-pressed`, `aria-controls`) and a `<TableView>` wrapper that renders the given `<table>` and hides the chart (`hidden` attribute) when pressed; the label swaps to "View as chart". State is local.
- `useChartKeyboard.ts`: roving focus helper for a list of marks: `{ activeIndex, onKeyDown }` supporting ArrowLeft/Right (and Up/Down for grids with `columns`), Home, End, Enter/Space → `onActivate(index)`.
- `scales.ts`: `attainmentDiverging(value) → cssVar` mapping attainment to `--div-n3..p3` with breakpoints `<92.5, <95, <100, 100, ≤102, ≤105, >105` (n3, n2, n1, 0 only when exactly 100 ±0.05, p1, p2, p3); `revenueSequential(value, max) → --seq-1..7` by 7 equal bins of `value/max`; `growthDiverging(value)` symmetric around 0: `< −5` → n3; `[−5, −2)` → n2; `[−2, −0.05)` → n1; `[−0.05, 0.05]` → `--div-0`; `(0.05, 2]` → p1; `(2, 5]` → p2; `> 5` → p3. A negative hue is never used for a value ≥ 0 and vice versa. Map legend labels for growth: `<−5%`, `−5 to −2%`, `−2 to 0%`, `0%`, `0 to 2%`, `2 to 5%`, `>5%`.
- `Choropleth.tsx` (client): props `{ geo: FeatureCollection; values: Record<marketId, {value:number; label:string; status:Status; name:string}>; metric: Metric; selected?: marketId; onSelect(marketId) }`. `geoNaturalEarth1().fitExtent([[8,8],[w-8,h-8]], landFeature)` (land excludes Antarctica, so the fit uses the populated world); draws `land` in `--surface-2` with `--border` stroke 0.5; each market `<path role="button" tabindex={0|-1 roving} aria-label={`${name}, ${STATUS_LABEL[status].toLowerCase()}, ${label}`} fill={scale(value)} stroke="var(--surface)" strokeWidth=1>`; selected gets stroke `--accent` 2 px; hover and focus show the tooltip with rows `[["Status", label], [metricLabel, value], ["Revenue", $x.xxM]]`; Enter/Space calls `onSelect`. Keyboard: Tab enters the map at the first market (alphabetical by name), arrows move through markets alphabetically. `<desc>`: "Choropleth of 13 markets coloured by {metric} for {period}. {n} on track, {n} at risk, {n} off track. Table available via View as table."
- Legend for the map: 7 swatches of the diverging scale with labels `<92.5%`, `92.5–95%`, `95–100%`, `100%`, `100–102%`, `102–105%`, `>105%` (attainment) or the sequential bins for revenue. Each label is centred under its swatch with a minimum gap between labels, and every percentage label carries a `%`. The swatches span up to 40 rem on one row from 1100 px viewport width; below that the legend wraps to two rows, the first three bins on the first row and the other four (the neutral bin and the high side) on the second. The three status dots are **not** in the legend (status is in the table and tooltip).

## 4. Overview feature (`src/features/overview`)
- `viewModel.ts` (server-safe): `overviewVM(ds, ctx)` returns `{ tiles: KpiTileVM[4], map: { values, metric, selected }, movers: { rising, falling } }`. Tiles (entity = `entityOf(ctx)`, period = `ctx.period`, basis = ctx.basis in analyst, month in overview):
  1. `PORTFOLIO REVENUE` (or `${ENTITY NAME} REVENUE` when drilled): headline `formatMoneyCompact(actual)`; delta `${formatPct(growth,{sign:true})} vs ${formatPeriod(prior period = same month last year)}` direction by sign; provenance per `kpiFor`.
  2. `FORECAST ATTAINMENT`: headline `formatPct(attainment,{sign:false})`; delta `${sign}${formatMoneyCompact(|variance|)} vs forecast` (e.g. `+$0.10M vs forecast`, `−$0.14M vs forecast`), direction by sign of variance.
  3. `GROWTH, YEAR ON YEAR`: headline `formatPct(growth,{sign:true})`; delta `YTD ${formatPct(ytdGrowth,{sign:true})} vs ${year−1}`; direction by sign of growth.
  4. `MARKETS NEEDING ATTENTION`: headline `formatCount(attention, total)`; delta `${at_risk} at risk · ${off_track} off track`, flat; provenance "Source · data.json". When the entity is a single market, this tile instead shows `STATUS` with headline the status label and delta `Attainment ${x}% · Growth ${y}%`.
  Values at portfolio/May 2026 must equal: `$22.85M` / `+7.3% vs May 2025`; `100.4%` / `+$0.10M vs forecast`; `+7.3%` / `YTD +6.1% vs 2025`; `6 of 13` / `4 at risk · 2 off track`. At Germany: `$1.68M` / `−9.7% vs May 2025`; `92.0%` / `−$0.14M vs forecast`; `−9.7%` / `YTD … vs 2025` (compute); `OFF TRACK`-tile: headline `Off track`, delta `Attainment 92.0% · Growth −9.7%`.
- `KpiRow.tsx` (server): four `KpiTile` (`src/components/KpiTile.tsx`, per §6.2) in a grid 4 / 2 columns.
- `MapCard.tsx` (client island): card with title `Markets by ${metricLabel}`, a metric Select (Attainment, Revenue, Growth) writing `setContext({metric})`, the legend, `Choropleth`, `ViewAsTable` with a 13-row table (Market, Region, Status badge, Attainment, Revenue, Growth) sorted by name. `onSelect` → `setContext({market})` (slice 3 makes this drill; wire it now). Fetches `/geo/markets.json` with `fetch` in a `useEffect` and caches in module scope; while loading shows the skeleton; on failure renders an inline Notice variant with title "Map unavailable", body "The market table below has the same data." and forces the table view.
- `TopMovers.tsx` (client): two columns Rising / Falling, three rows each: name (`--ink` 500), value right-aligned coloured by sign with real minus, and an `AskWhy` icon button (`message-square-text` 16 px, `aria-label="Ask why {name} is {status}"` or for Germany `"Ask why Germany dipped"`). Clicking fills the composer via a shared `useAskWhy()` in `src/features/assistant` that exposes `prefill(text)` through a small context provider mounted in Layout. Caption `Growth YoY, ${period} · Source · data.json`.
- `Overview.tsx` (server): computes the VM and renders KpiRow, MapCard, TopMovers inside `ErrorBoundary`s.
