# Slice 5: Ask, stream, stop. Spec

Depends on slices 0 to 2 (panel exists). Inputs: CONTRACT.md; design-system.md §6.5 states 1, 5, 6, §6.6; domain-model.md §7; architecture.md §7 (answer machine); user-flows.md slice 5.

## 1. Files
- `src/lib/stream/chatClient.ts`: `askStream(question, { signal, onEvent }): Promise<void>`. POST `/api/chat` JSON `{question}`; read `res.body` with `TextDecoder(stream:true)`; buffer; split on `\n\n`; for each block take lines starting with `data:`; `parseSseLine`; call `onEvent(event)`; on `AbortError` resolve quietly after calling `onEvent({type:"aborted"})` (an internal event, not in the contract, typed separately); on non-2xx throw `new ChatHttpError(status)`; on parse error throw `ChatProtocolError`. Keep the last partial block in the buffer across reads.
- `src/features/assistant/useAnswerMachine.ts`: `useReducer` with the exact union from architecture.md §7 plus `question: string` and `id: string` on every non-idle state; actions `ASK(question)`, `TOKEN(value)`, `DONE(payload)`, `STOP`, `ERROR(message)`, `RETRY`. Token batching: tokens append to a ref and a single `TOKEN_FLUSH(text)` dispatches per animation frame. `DONE` resolves citations via `resolveCitation(ds, c, answerText)` (ds comes from a `DatasetContext` provider that exposes the markets, regions, products and periods only, serialised into the client, not the series). `RETRY` re-asks the same question as a new answer; the old one stays.
- `src/features/assistant/AnswerList.tsx`: newest answer at the bottom; the list scrolls to the new card on ASK; `aria-live="polite"` region announcing "Answer complete" on DONE, "Answer stopped" on STOP, "Answer failed" on ERROR (visually hidden).
- `src/features/assistant/AnswerCard.tsx`: per design-system.md §6.5: question echo; card; text in `--text-answer`; while `streaming` the caret; footer per state: streaming → `STREAMING…` + Stop (secondary, `square` 12 px); done → `ConfidenceMeter` + `Show sources` (disabled until slice 7 renders the table; render the button now with the Collapsible containing a placeholder "Sources" table shell); stopped → pill `Stopped · partial answer` after the text, footer caption `PARTIAL · NO SOURCES ATTACHED` + Retry (ghost). Chips render in slice 6; in this slice the citations are resolved and stored but the chip row renders plain `<span>` placeholders with the label text (so slice 6 only swaps the component).
- `src/components/ConfidenceMeter.tsx` per §6.6 with the exact words, meanings and icons.
- `Composer`: `disabled` while an answer is streaming; Send turns into nothing else (Stop lives in the card).
- `Panel.tsx`: owns the machine; Suggestions `onPick` now fills **and sends**.
- `src/app/api/chat/route.ts`: the reference handler verbatim, typed with `SseEventSchema` on the way out in dev (`assert` the object parses before enqueueing).
