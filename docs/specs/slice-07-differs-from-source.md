# Slice 7: The assistant disagrees with the data. Spec

Depends on slice 6. Inputs: design-system.md §6.5 (differs variant), §6.9, §6.14; preview-spec.md §9.4 state 2 and preview-spec-addendum-sources.md; user-flows.md slice 7.

## 1. Files
- `CitationChip` disagreement variant: `triangle-alert` 12 px in `--warn-text` after the label; `aria-describedby` → hidden "Assistant says {assistant}; source data says {source label lowercase}"; Tooltip on hover/focus with the two-row table `Assistant: At risk` / `Source (data.json): Off track`.
- `src/features/assistant/SourcesTable.tsx`: Collapsible content; `<table>` columns Claim, Entity, Period (mono), Source value, Assistant; rows built from resolved citations: Claim = the inline phrase if mapped else the label; Entity = `entityName`; Period = resolved period; Source value = for market/product targets at latest: `${STATUS_LABEL} · ${attainment}% attainment` (+ ` · ${revenue}` for state 3 rows); for other periods: `${formatMoneyCompact(actual)} actual · ${attainment}% of forecast`; for an anomaly period on that market additionally ` · −27% vs Feb (anomaly note)` using `momChangePct`; Assistant = the claim's status phrase if any else a short echo from `inlineMap` (`assistantWord` field: "Revenue fell", "Steepest drop", "Across products", "Under plan", "Smaller drag", "At risk", "Sharp dip"). Disagreement rows get the icon before Claim and `--warn-text` in Assistant. Unresolved citations render a row "Could not resolve" with the label and `—`. Caption per fixture from `inlineMap.caption` (the three captions in preview-spec.md §9.4 and the addendum). Inside the 380 px panel the table scrolls horizontally in a focusable region with `aria-label="Sources table"`.
- The Show sources disclosure defaults open only when any citation has a disagreement (state 2); otherwise closed.
